# 全民学术打假 / Academic Integrity Skill

> **Skill 本质上是一种结构化思维方式。**  
> 开发这个 Skill 并不是为了攻击某个人，而是在 AI 时代，每个人都有权利受惠于 AI，人人都能掌握系统化的思考模式，对学术祛魅、对权威祛魅，让真正的学术去照亮人类文明的发展进程，而不只是一小部分人的特权。

---

## 📖 简介

「全民学术打假」是一个面向公众的**学术真实性分析框架**，帮助你在信息爆炸的时代建立系统化的判断力。

它整合了 **9 大工作模式**，覆盖从个人学者、高校导师、论文质量、学术机构到媒体话术、互联网神棍生态的全链条分析：

| 模式 | 功能 |
|------|------|
| **M1** 学术打假报告生成 | 对任何学者进行全面的学术可信度调查 |
| **M2** 高校导师可信度分析 | 帮助学生识别真正值得追随的科研导师 |
| **M3** AI 论文灌水检测 | 识别低质量 AI 拼接论文与学术工业化生产 |
| **M4** 野鸡学术机构识别 | 识别掠夺性期刊、收费院士体系与论文产业链 |
| **M5** 媒体造神指数分析 | 拆解 PR 包装结构，分析公众认知如何被操盘 |
| **M6** 青年学者真实性评分 | 区分真正潜力股与"早熟包装" |
| **M7** 学术包装话术识别 | 识别权威幻觉语言与认知压制技术 |
| **M8** 中文互联网学术神棍图谱 | 建立伪学术权威的生成机制地图 |
| **M9** 综合全面审计 | 整合全部维度的终极深度报告 |

## 🎯 核心理念

- **不是网暴**：不人身攻击，不下绝对定论，不情绪化批判
- **证据导向**：采用"事实 → 证据 → 逻辑推导"的冷静调查语言
- **祛魅而非猎巫**：区分"能力差"与"不诚信"，区分"优秀"与"被神化"
- **赋权公众**：让每个人都能独立判断学术真实性

## 🚀 使用方法

本 Skill 设计为与 AI Agent（如 Claude、Kimi、ChatGPT 等）配合使用。

### 方式一：直接导入

将 [`SKILL.md`](./SKILL.md) 的内容作为 System Prompt 或自定义指令导入你的 AI 助手，然后直接输入目标人物/论文/机构名称即可。

### 方式二：分模式调用

根据你的需求，指示 AI 进入对应模式：

```
使用全民学术打假的 Mode 3，分析这篇论文是否存在 AI 灌水嫌疑：
[粘贴论文标题或摘要]
```

```
使用全民学术打假的 Mode 2，帮我评估这位导师是否值得报考：
张三，某大学计算机学院
```
